Speed

Big sheets open fast with only the first rows. Viewers click Load all (top bar) to get every row. Sort, filter, search and totals work on the loaded rows. Choose "All rows" if they must always cover everything.

Text sizes

The title size is in Header bar above. Rows get taller automatically for bigger text.

Needed for dashboard actions from this table (Filter / Highlight / Go to URL). Ctrl/⌘-click adds rows, Shift-click selects a range, Esc clears.

Rules run top to bottom; a later rule wins when two color the same cell.
