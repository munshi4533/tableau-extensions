Combine days tells each measure how to turn daily values into MTD / last month: Sum for amounts and counts, Latest value for balances. Calculated KPIs roll up each part first, then calculate, e.g. Average Loan Size = [Loan Amount] / [Loans].

Big number

All cards use this unless a card picks its own. "Last day" is the latest date in the data; MTD runs from the 1st to that date and is compared with the same days of last month (LMTD). YTD runs from 1 January and is compared with the same days last year (LYTD).

Periods to offer (buttons and small values)

Total adds up every date in the data, so it follows your Tableau filters (e.g. this year). It has no comparison.

Status icon

Green / yellow / red is set per card (Cards → Number format, target, chart & icon color): by change, by value thresholds or by % of target. Leave yellow empty for green / red only. The icon hides itself when there is nothing to compare (e.g. Total); each card can also set Icon to Always or Hide.

Under the number

Chart under the number

Every card uses this unless it picks its own chart (Cards → Number format, target & chart).

Extra smooth draws soft waves; dips look a little shallower, the numbers in the tooltip stay exact.

Dates and running total

Amounts and counts add up day by day. Ratios, averages and balances are recalculated "to date", e.g. Approval Rate = all approved so far ÷ all submitted so far. Bar and line colors can be set per card in Cards.

Mini trend line

Automatic uses days for Last day (or short history) and months otherwise. Month by month is like for like: with MTD each month covers the same days (1st–8th), with Last month full months.
